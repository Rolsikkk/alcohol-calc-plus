# Калькулятор спирта+

Нативное Android-приложение с набором инженерных калькуляторов для домашнего
дистилляционного хобби: разбавление спирта, ректификация, смешивание растворов,
таймер отбора, температурные поправки спиртометра/ареометра, расчёт давления/вакуума
и мощности нагревателя. Без рекламы и трекеров; единственный сетевой вызов —
необязательная проверка новой версии на GitHub при запуске (см. ниже).

Репозиторий: https://github.com/Rolsikkk/alcohol-calc-plus

## Стек

- Kotlin + Jetpack Compose (Material 3), single-activity, Compose Navigation.
- MVVM: по одному `ViewModel` на экран, состояние — `StateFlow`.
- Чистая логика расчётов вынесена в `core/calculators/*` — обычные Kotlin-функции
  без зависимостей от Android, покрыты unit-тестами JUnit (без эмулятора).
- Настройки (видимые вкладки, язык RU/EN) — `androidx.datastore.preferences`.
- minSdk 24, targetSdk 35, compileSdk 35.

## Как собрать

Нужны JDK 17+ и доступ к Android SDK (в `local.properties` уже прописан путь;
поправьте `sdk.dir`, если открываете проект на другой машине). Gradle ставить
отдельно не нужно — используется Gradle Wrapper.

```bash
./gradlew assembleDebug
```

Debug-APK появится в:

```
app/build/outputs/apk/debug/app-debug.apk
```

Проект также открывается в Android Studio (Open → выбрать папку проекта) —
Gradle-синхронизация подтянет всё автоматически.

## Как запустить тесты

```bash
./gradlew test
```

Тесты лежат в `app/src/test/kotlin/.../core/calculators/` — по 2–3 кейса на
калькулятор (нормальный расчёт со сверкой ожидаемого числа + граничный/некорректный
ввод, где результат должен быть предсказуемым — прочерк/`null`, без `NaN`,
`Infinity` или падения).

│   ├── RectificationCalculator.kt — 2. Ректификация (головы/тело/хвосты)

│   ├── ThermometerCalculator.kt   — 5. Спиртуозность t(C)
│   ├── HydrometerCalculator.kt    — 6. Плотность/Brix t(C)
│   ├── PressureCalculator.kt      — 7. Давление/Вакуум (фазовое равновесие)
│   ├── HeaterCalculator.kt        — 8. Мощность нагрева (ТЭН)

## Какие формулы приближённые и почему

- **Давление/Вакуум** (`PressureCalculator.kt`): используется упрощённая таблица
  фазового равновесия этанол-вода (13 узлов, линейная интерполяция) и линейный
  коэффициент 0.037 °C/мм рт. ст. для пересчёта точки кипения при отклонении от
  760 мм рт. ст. Реальная диаграмма равновесия нелинейна, а коэффициент
  давление→температура сам зависит от состава смеси — здесь взято приближение,
  достаточное для планирования перегонки под вакуумом в домашних условиях, но не
  для лабораторной точности. Это явно указано подсказкой под результатом на экране.
- **Плотность/Brix t(C)** (`HydrometerCalculator.kt`): температурная поправка
  ареометра берётся с постоянным коэффициентом 0.2 (единиц SG×1000 на градус) —
  в реальности коэффициент немного меняется в зависимости от самого значения SG,
  но для рабочего диапазона сусла разница пренебрежимо мала.
- Обе таблицы (плотность спирто-водного раствора и фазовое равновесие) заданы по
  условию задачи и интерполируются линейно между узлами; за пределами диапазона
  значения не экстраполируются, а «прижимаются» (clamp) к крайнему узлу.

## Обработка некорректного ввода

Везде, где по формуле возможно деление на 0 или физически бессмысленный результат
(например, разбавление до крепости выше исходной, нулевое время отбора, нулевое
паспортное напряжение ТЭНа), калькулятор не пытается посчитать — поля результата
показывают прочерк «—», а не `NaN`/`Infinity`/краш. Это проверяется отдельными
unit-тестами для каждого калькулятора.

## Взаимно редактируемые поля мл / гр / %

На экранах «Разбавление» (строка «Спирт»), «Смешивание» (каждый раствор) и
«Ректификация» (строка «Спирт сырец») поля объём/масса/крепость можно
редактировать в любом порядке:

- правите крепость (%) — объём остаётся как есть, масса пересчитывается;
- правите объём или массу — крепость остаётся как есть, пересчитывается вторая
  из пары объём/масса.

Так можно охарактеризовать имеющийся спирт либо измеренным объёмом, либо
взвешенной массой. Поля, которые являются чистым результатом всей цепочки
расчёта (вода и итог на экране разбавления, головы/тело/хвосты на
ректификации, итог на смешивании), остаются только для чтения — их обратный
пересчёт потребовал бы решения всей формулы в обратную сторону и не
реализован.

## Проверка обновлений

При каждом холодном запуске приложение (в фоне, один раз за жизнь процесса)
обращается к `https://api.github.com/repos/Rolsikkk/alcohol-calc-plus/releases/latest`.
Если версия релиза новее текущей (`BuildConfig.VERSION_NAME`), показывается
диалог с предложением скачать и установить APK; кнопка «Позже» откладывает
запрос до следующего холодного старта (ничего не сохраняется на диск — просто
внутреннее состояние текущего запуска). При сбое сети проверка молча
пропускается, без ошибок и без блокировки интерфейса.

Чтобы выпустить новую версию: поднять `versionCode`/`versionName` в
`app/build.gradle.kts`, собрать `assembleDebug`, и опубликовать релиз с тегом
`v{versionName}` (например `v1.1`) и приложенным `.apk`-файлом:

```bash
gh release create v1.1 app/build/outputs/apk/debug/app-debug.apk --title "v1.1" --notes "..."
```
